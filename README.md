# Na Mochila — Sistema de Gestão

Aplicação web para a gestão do **Na Mochila**, associação de robótica educacional do Médio Piracicaba (MG).

O primeiro módulo é o **controle financeiro**: cadastro de alunos, responsáveis e matrículas, controle de mensalidades e pendências, despesas, receitas e patrocínios, saldo, fluxo de caixa e previsão de receita.

## Tecnologias

| Parte | Tecnologia | Hospedagem |
|---|---|---|
| Frontend | React + TypeScript | Vercel |
| Backend | Python + FastAPI | Render |
| Banco de dados | PostgreSQL | Neon |
